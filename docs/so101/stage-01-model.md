# 第一阶段：模型与关节对齐

## 目标

输入一组五关节角，在 MuJoCo 中显示预期 SO-101 姿态。
本阶段不接入规划器、不进行硬件控制，也不要求实现完整逆运动学。

## 第一个小任务

1. 先确认已有的本地 SO-101 预览模型是否仍可复现；若没有可用资产，从官方仓库选定版本。
2. 保存模型和依赖网格，补全 models/so101/manifest.json，核对许可证。
3. 建立独立 Python 环境，安装项目的 sim、dev 可选依赖。
4. 创建最小模型加载入口：打印所有关节名称、类型、限位及五关节对应的状态索引。
5. 选取模型限位内的姿态，逐个改变一个关节，记录实际旋转方向和截图。

## 验收

模型来源可追溯；依赖网格完整；每个关节可独立预览；关节索引不硬编码；
异常路径能明确报错；记录至少两组非零姿态。第一阶段通过不代表动力学或碰撞已验证。
