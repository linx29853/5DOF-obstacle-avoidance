# 阶段路线与验收

实际代码推进与完成证据见 [初步代码实现勾选清单](implementation-checklist.md)。五关节正运动学已有实现并通过 8 组姿态对照；其余阶段按清单逐项验收，脚手架不代表学习成果。

| 阶段 | 交付与验收证据 |
| --- | --- |
| 1 模型 | 固定来源版本；成功加载；五关节映射、方向、零位和限位核对记录；姿态截图 |
| 2 碰撞 | 桌面和已知障碍；全臂与自碰撞；无碰撞、接触、穿透及限位案例；检查离散边 |
| 3 规划 | 迁移自己的 RRT-Connect；关节目标；路径简化后复核；多种子与预算耗尽记录 |
| 4 轨迹 | 逐关节速度/加速度限制；轨迹复核；区分运动播放和动力学跟踪；记录跟踪误差 |
| 5 真机 | 核对单位与标定；空场低速执行后加入静态障碍；反馈记录；失败时停止继续下发 |
| 6 感知 | 相机至基座标定；障碍位置/尺寸及误差测量；感知快照→规划→执行静态闭环 |
| 7 评测 | 固定测试集；成功率、耗时、路径长度、跟踪误差及可验证间隙；失败原因与复现命令 |

先采用固定夹爪、已知起终关节角和简单静态几何体。笛卡尔目标与逆运动学在关节空间
闭环后引入。动态障碍在线重规划属于后续扩展，不是第一版要求。

每次实验记录：配置、模型来源提交、代码提交及未提交改动、依赖、种子、预期与实际结果。
仿真几何间隙与真机测量间隙分别标注。有限采样检查不宣称连续安全保证。
