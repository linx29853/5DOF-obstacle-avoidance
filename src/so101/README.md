# SO-101 实现入口

当前状态：仅建立包与职责约定，尚未实现或验证 SO-101 功能。

核心算法由学习者逐步完成；先做最小实验，再提取模块，不提前创建空壳类。
原有 src/ 下二连杆模块保持兼容。

后续按实验需要逐步增加：

| 模块 | 职责 | 输入与输出约定 |
| --- | --- | --- |
| model | 模型加载、关节映射、正运动学 | 五关节角 → 各连杆与工具坐标变换 |
| collision | 全臂、环境与自碰撞检查 | 构型与场景 → 有效性；需要时输出最小间隙 |
| planning | 将现有 RRT-Connect 解耦并推广 | 起终构型、限位、检查函数 → 路径或失败 |
| trajectory | 路径时间参数化 | 路径及逐关节限制 → 时间、位置、速度、加速度 |
| simulation | MuJoCo 姿态播放与动力学执行 | 同一模型和轨迹；区分姿态播放与真实跟踪 |
| hardware | 真机状态读取、单位转换、位置指令 | 显式连接；仿真入口不可隐式连接真机 |
| perception | 相机标定与障碍物建模 | 相机观测 → 基座坐标系中的障碍物 |
| evaluation | 统一实验记录和结果统计 | 配置、随机种子、轨迹、实际观测 → 指标 |

默认规划变量为五个机械臂关节，夹爪单独管理；固定开度也必须计入碰撞几何。
内部统一 m、rad、s，硬件单位转换只放在硬件边界。
关节顺序见 configs/so101/simulation.json；模型限位与零位必须由模型和实测确认。
